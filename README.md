# DevOps SR4

Пакет `sr4-demo` містить функцію `hello()`, яка повертає тестове привітання.
Для встановлення після збирання виконайте `python -m pip install dist/sr4_demo-0.1.0-py3-none-any.whl`.

Із локального devpi пакет встановлюється командою `python -m pip install --index-url http://127.0.0.1:3141/alexander/dev/+simple/ sr4-demo==0.1.0`.
