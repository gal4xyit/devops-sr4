# Changelog

## [0.1.0] - 2026-11-03

### Added
- Тестовий JSON-сервер і навантажувальний тест Molotov.
- Початкова версія пакета sr4-demo з функцією hello().
- Збирання sdist і wheel через pyproject.toml та python -m build.
- Публікація через twine і перевірка встановлення з локального devpi.
- Systemd-сервіс для запису повідомлень щохвилини.
- Результати перегляду журналів і моніторингу дисків.

### Fixed
- Виправлення помилок у початковому випуску відсутні.

### Security
- Виправлення безпеки в цьому випуску відсутні.
